# Codex Pulse v0.9.18 Beta

这一版优化首次开启体验和圆角图标。已有用户运行同一个安装器升级，保留本机设置和历史。

## 圆角图标

保留原有图形和绿色，缩小底板、增加留白，修复导出时透明圆角被白底填满的问题。
PNG、64 px 回退图及 macOS ICNS 同步更新。构建会逐档检查实际透明边缘，防止方形白底再次出现。

## 开启自动保护

安装结束后直接看到原生窗口。看清用途，点击“开启自动保护”即可提交本人授权，
不需要打开 CLI、输入 `/hooks` 或按 `t`。设置窗口底部“保护授权”可再次进入。

技术定义放在可展开的权限详情中。取消不授权；失败不显示成功；定义变化要重新审查。
此窗口由 Codex Pulse 提供，不冒充系统或 OpenAI 的官方授权窗口。

成功后显示“保护授权已确认”。新会话生效，当前任务不会被自动打断。
需要马上加载时可主动点击“重启 Codex”，该操作会停止当前任务；也可点击“完成”，方便时重开。

自动用卡是独立选项，不包含在此授权中。通知权限仍由 macOS 询问。

## 验证

隔离配置使用真实 Codex，验证确认前不写信任、确认后 trusted、重启后保留、定义变化后重新待审。
浅／深色原生按钮测试分别覆盖取消和开启；不调用模型、不修改真实用户授权、不消耗重置卡。

兼容已审查的 0.9.17 定义。后台监控与暂停续跑核心未在本轮重写。
