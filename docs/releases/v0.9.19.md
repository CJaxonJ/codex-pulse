# Codex Pulse v0.9.19 · Beta

本次重点是安装可靠性和界面可读性，没有新增后台权限或自动用卡授权。

## 改了什么

- 安装前先检查账号、构建依赖与现有插件。先构建候选 App，校验后再切换。
- 完整安装与单独更新共用回滚流程：启动或诊断失败，恢复旧 App 和运行时。
- 安装、更新、卸载互斥。无法确认服务状态或发现上次遗留备份时停止，不覆盖证据。
- 兼容的已审查插件保持原样。现有插件不兼容、关闭或定义不同，先停止并解释，不删除旧授权。
- 卸载移除本产品的插件、App 与服务，保留偏好、检查点和本机历史。
- 设置页突出额度与恢复时间，额度条按实际数值显示，过期数据置灰；精简首页和安装说明。

## 本轮验证的边界

- 故障注入覆盖依赖、启动、诊断、服务停止失败、并发安装和遗留备份。
- 独立 Codex 配置目录中，使用真实 CLI 验证插件安装、重复安装、卸载；不授予 Hook 信任。
- 独立命名的 launchd 测试服务验证真实进程切换和失败回滚；不会操作用户的真实 Pulse 服务。
- 独立真实 App Server 会话验证已注册 Hook 的暂停、检查点、断联后恢复、替换 watcher、模型实际产出及重复唤醒拦截，分别覆盖有／无初始 Goal。

上述续跑测试注入低额度／恢复额度样本，不是通过耗尽账号来测试。它不能代替一台干净 Mac 上的完整首次安装、当前已打开桌面线程的重载，或物理睡眠验收。

## 开始使用

下载 `Codex-Pulse-0.9.19-macOS.zip`，解压后双击 `安装 Codex Pulse.command`。
已有兼容插件无需重复审查；新授权对新会话生效，方便时重开 Codex。重启会停止当前任务，不会自动执行。

自动用卡仍默认关闭、单独授权；睡眠和离线可能错过卡片到期。Tibo 公共数据源不是官方保证。

完整产品仍通过 macOS 安装包提供，未上架官方插件目录。
