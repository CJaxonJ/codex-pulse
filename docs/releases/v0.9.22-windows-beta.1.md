# Codex Pulse · Windows Beta 1

首个公开 Windows x64 测试版，适用于已登录 Codex 的个人 Plus / Pro 账号。

## 能做什么

- 查看额度、提前提醒，接近 10% 时保护后续工具操作并保存进度。
- 接收 Tibo 重置相关消息，回看原文和续跑计划。
- 在原生设置窗口调整提醒和保护方式，也可直接解除 10% 暂停。
- 双击安装、开始菜单入口、开机启动、升级回滚和保留历史的卸载。

包含 Node 22，无需单独安装 Node、配置 X 凭证或 API 绑卡。

## 怎么安装

下载 `Codex-Pulse-0.9.22-beta.1-Windows-x64.zip` 并完整解压，双击 `CodexPulse.exe`。安装后进入“保护与用卡”审查授权，方便时重开 Codex。请保留解压目录，之后也从这里升级、修复或卸载。

## 已知限制

- 自动续跑仍是实验功能，依赖 Codex 版本及历史接口；不支持或无法安全核实时会提示手动继续。
- 真实账号在断网、锁屏和物理睡眠后的续跑尚未完整验收，提醒也可能延迟。
- 安装包尚无 Windows 发布者签名，仅从本项目 Releases 下载；不建议关闭系统安全保护。
- 自动用卡默认关闭，需单独授权，不会替你购买重置卡。

安装与回滚采用真实 Windows 进程、系统计划任务、官方 CLI 及隔离账号对端验证；自动测试不使用真实重置卡，不代表真实模型或物理睡眠验收。
