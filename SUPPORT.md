# Support

Codex Pulse is an independent beta project. It is not an OpenAI support channel
and cannot change account quota, subscription status, or reset-credit state.

Before opening an issue:

1. Confirm that Node.js 20 or newer is installed.
2. Run `node bin/codex-pulse.mjs doctor` from the installed runtime.
3. Search existing issues for the same symptom.

For a bug, use the bug-report form and include the redacted doctor output,
Codex Pulse version, macOS version, plan type, and approximate time of the
problem. Never include credentials, reset-credit IDs, private prompts, or
proprietary source code.

Use GitHub's private vulnerability-reporting form for security issues. General
Codex account and billing problems should go to official OpenAI support.
