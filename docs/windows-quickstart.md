# Windows 使用步骤（待 Windows 验收后分发）

当前仍为内部验收，不代表 Windows 已公开发布。以下流程对应正在测试的安装窗口。

1. 下载 Windows x64 ZIP，完整解压。双击目录里的 **CodexPulse.exe**，点击“安装”。本机需要先安装并登录 Codex；不需要另外安装 Node，也无需管理员权限。
2. 安装完成后点击“打开设置”，进入“保护与用卡”→“审查保护授权”，亲自确认本产品的保护定义。安装不会代替你授权，也不会强制重启正在运行的 Codex。
3. 正常使用 Codex。之后可从开始菜单或后台图标打开设置、消息历史和续跑计划。自动用卡默认关闭，需要单独确认。

保留解压后的安装目录。升级、修复或卸载时，重新打开其中的 **CodexPulse.exe**；卸载会再确认一次，保留任务进度、偏好、额度历史和用卡记录。自定义数据目录的快捷方式保存在该目录的 `shortcuts` 下，不覆盖默认配置的开始菜单入口。

安装中断后，重新打开安装包重试。程序会先核实上次记录；若提示文件或任务状态无法确认，请保留现场。正在执行的托管任务、等待授权和未知状态会阻止升级或卸载。

只有从本项目可信发布来源下载的完整安装包可用。校验和与完整性清单用于检查文件变化，不代表微软发布者签名。原生 Windows、断网、锁屏与物理睡眠的验收范围以发布说明为准。
