# Codex Pulse v0.9.18 · 本地候选版

这一版只改首次开启体验，公开版仍为 v0.9.17，尚未发布 v0.9.18。

## 开启自动保护

安装结束后直接看到原生窗口。看清用途，点击“开启自动保护”即可提交本人授权，
不需要打开 CLI、输入 `/hooks` 或按 `t`。设置窗口底部“保护授权”可再次进入。

技术定义放在可展开的权限详情中。取消不授权；失败不显示成功；定义变化要重新审查。
此窗口由 Codex Pulse 提供，不冒充系统或 OpenAI 的官方授权窗口。

成功后显示“保护授权已确认”。新会话生效，当前任务不会被自动打断。
需要马上加载时可主动点击“重启 Codex”，该操作会停止当前任务；也可点击“完成”，方便时重开。

自动用卡是独立选项，不包含在此授权中。通知权限仍由 macOS 询问。
