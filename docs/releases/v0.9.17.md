## 新增

- **原生设置窗口**：浅色／深色随系统，可调整 15%–80% 提前提醒比例、声音、重要窗口常驻、公共重置和临期卡提醒。
- **暂停计划预览**：按任务查看原目标、已完成、剩余和下一步，以及真实额度窗口给出的最早恢复时间。没有依据的剩余耗时明确显示未知，不额外调用模型。
- **分级提醒**：重要事件红色、提前提示橙色，区分公共预告、公共确认、个人到账和普通 5 小时恢复。
- **可选临期卡挽救**：默认关闭。明确授权后，仅对绑定的个人账户，在卡不足 10 分钟到期且确有额度可重置时处理最早到期的一张；支持幂等重试，兑换后重读额度。

## 核心修复

- 恢复不再仅把 Goal 改成 active：通过正式队列唤醒所属会话，并区分“请求已提交”和“实际开始执行”。
- 补齐推理／压缩阶段额度耗尽、缺失 Stop、断联和后台重启的检查点恢复路径。
- 防止重复唤醒、第一条续跑工具与后台状态竞争，以及更换监控进程后误启动。
- 保留原始目标；文件变化、新任务、待审批或执行状态未知时先停下并说明原因。

## 安装与升级

解压 macOS ZIP，双击 `安装 Codex Pulse.command`，按引导允许通知、审查 Hook 并确认重启。
需要 Node.js 20+、Apple Command Line Tools 和已登录的 Codex。
升级沿用安装器并保留设置；新用户的自动用卡始终默认关闭。

不需要 OpenAI 开发者身份验证、API 绑卡或 X 凭证。不要把自动生成的 Source code 当作安装包。

## 验证与边界

- 204 项自动测试，以及原生常驻提醒、只读计划预览、浅／深色设置保存和关闭授权测试通过。
- 隔离协议测试覆盖丢失兑换响应、跨进程重试和并发；**没有用真实重置卡做测试**。
- 真实 App Server 验收使用独立测试会话，不把当前用户聊天作为实验对象；真实模型测试消耗少量普通额度。
- Hook 必须本人审查。保护发生在支持的生命周期边界，不承诺任意推理中都恰好停在 10%，不能撤销已经执行的工具。
- 睡眠、断网、退出监控或平台不可用可能延迟续跑、错过临期卡；Tibo 外部数据源也不保证每次预告必达。
- 系统横幅颜色由 macOS 控制；红／橙等级显示在应用自己的提醒窗口中。
