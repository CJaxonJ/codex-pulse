# 一次确认开启保护

目标：普通用户不需要打开终端、读命令或记住快捷键。首屏只回答“有什么用、会做什么、如何退出”。
技术详情按需展开，不以读懂代码作为使用条件。参考 Apple 的上下文权限与简短引导原则，
并保留 Codex 对当前定义的本人审查要求。

## 本轮范围

1. 原生“开启自动保护”窗口：暂停／保存／恢复的用途、本地保存范围、可选项不捆绑。
2. 主按钮为“开启自动保护”，次按钮为“稍后开启”；读取或取消不改变授权。
3. “权限详情”折叠展示准确来源与定义，供有需要的人核查。
4. 用户点击后重读当前定义，只确认刚刚展示的 Codex Pulse 六项定义；定义或配置变化时重新审查。
5. 使用 Codex `config/batchWrite` 原子保存精确哈希并回读 `hooks/list`。不写其他插件，不使用信任绕过参数。
6. 成功文案区分“授权已确认”和当前会话是否已加载。重启需用户另行主动选择，不中断正在进行的工作。
7. 首次安装直接进入此窗口；设置里保留可再次打开的入口。不再默认弹出 CLI。

自动用卡仍默认关闭且单独授权。通知权限仍由 macOS 自己询问。本轮不重写监控、暂停和续跑核心。

## 验收

- 不确认、取消、关闭窗口：不写信任；只显示窗口不能算开启。
- 确认：真实 Codex 返回 trusted；替换进程后仍为 trusted；定义改变后重新进入 modified。
- 过期审查、范围外插件、重复或缺失定义、配置竞争和写入失败：不盲写、不显示成功。
- 原生浅／深色界面首屏无命令，详情可展开；取消与确认由真实按钮驱动。
- 隔离环境测试，不改变真实用户授权、不消耗模型额度或重置卡。

## 技术证据与边界

2026-10-26 隔离 CODEX_HOME 实测：官方配置 RPC 写入当前定义哈希后状态 trusted，
进程重启后仍 trusted，命令变化后 modified。公开文档没有独立 hooks/trust RPC；
这里使用当前版本实际支持的配置接口，不宣传为 OpenAI 官方提供的第三方授权弹窗。
不同版本不兼容时明确失败，保留手动审查作为高级故障处理，不伪造授权。
