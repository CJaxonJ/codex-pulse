# Windows 适配验收记录

状态：开发中，**尚未支持对外安装，不是已发布的 Windows 版**。目标是原生 Windows 上的完整额度监控、通知、用户本人保护授权、暂停与恢复、安装升级及卸载，不以 WSL 或只跑 CLI 代替。

## 必须完成的验收

- [ ] Windows 原生运行层：Codex exe/npm 启动、中文／空格路径、本地数据目录、进程退出错误。
- [ ] Hook Windows 命令：实际 shell 执行、信任定义校验、本人授权与变化后重新审查。
- [ ] 提醒与简洁设置界面：等级、常驻提醒、原帖回看、续跑计划、偏好及单独用卡授权。
- [ ] 用户级后台：登录后启动，异常退出重启，断网／睡眠恢复，不需要管理员权限。
- [ ] 安装包：依赖处理、安装前检查、升级失败回滚、重复安装和完整卸载（默认保留历史）。
- [ ] 核心链路：真实 Windows 进程测试 10% 阻止新工具、保存原目标和计划、额度恢复后同一会话仅续跑一次。
- [ ] 恢复安全：后台重启、并发、重复事件、正在运行／状态未知、审批、取消、工作区变更。
- [ ] macOS 完整回归，不改用户本机现有安装和信任。
- [ ] Windows runner 执行证据；物理睡眠和桌面通知若未实测，明确保留未验收状态。

## 官方依据

- [Hooks](https://learn.chatgpt.com/docs/hooks)：Windows 有独立 `commandWindows`；插件提供 `PLUGIN_ROOT`，安装不等于信任。
- [App Server](https://learn.chatgpt.com/docs/app-server)：stdio JSONL 初始化、请求与响应保持原协议；不能因为程序能连接就声称真实任务已续跑。

首次检查：原有后台、通知、数据目录和插件安装器均为 macOS 专用。当前先抽出跨平台路径／进程调用；后续按以上完整范围继续，不缩减成“Node 单测通过即支持 Windows”。
